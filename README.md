# 🧠 캐릭터 심리검사 (Psych Lab) — SillyTavern 확장

캐릭터 카드에게 심리검사를 풀게 하고, 결과를 **가치관(무엇에 반응하나)**과 **성격(어떻게 반응하나)** 두 축으로 정리해 카드·로어북에 붙여 넣을 수 있게 만드는 오락용 도구예요. 모델의 원작 지식이 틀린 게 아니라 **클리셰가 카드를 덮는 문제**("츳코미 캐릭터 → 항상 츳코미")를 줄이려고, 캐릭터를 여러 각도에서 분류해 둡니다.

- 버전 **0.6.0** — 검사 5개. 가치관: 도덕 기반(MFQ-2 원문 36) · **Schwartz 10가치(PVQ40 한국어판 원문 40)** / 성격: 빅파이브 30세부(IPIP-NEO-120 원문 120) + 빅파이브가 못 재는 축만 보강(꾸밈 없음·탐욕 회피 16, VIA 강점 5개 30). **종합 결과** 화면. 묶음 기본 5. 0.5.0에서 환산 라벨(MBTI·A/T·에니어그램·대인 자세)은 뺐고, **NPC 뽑기**(간소화판: 설정 + 로그 → 모델 호출 1번 → 다섯 검사 라벨 세 줄)가 들어갔어요. 0.5.1: 뽑은 NPC는 **그 채팅방에** 저장(다른 채팅에서는 안 보임). 0.6.0: **카드 안의 인물 고르기** — 다인봇처럼 인물이 로어북 항목으로 들어 있는 카드는 항목 하나를 골라 그 인물만 검사.
- 자동으로 끝까지 진행 → 검사별 결과에서 문항별 캐릭터의 답과 이유 확인 → 마음에 안 드는 답을 내 선택으로 교체 → **종합 결과**에서 한 화면으로 읽고 공유용 요약 복사
- 카드·로어북·프리셋·채팅을 **자동으로 바꾸지 않아요.** 복사만 해요.
- **NPC 뽑기** — 다인봇 NPC가 다 비슷해질 때. 이름 + 이미 만든 설정(정답) + 지금 열린 채팅 로그 → 모델 호출 1번 → `[이름] 자리·말투 / 가치관: … / 성격: …` 세 줄. 복사해서 로어북 항목에 붙이면 고정 NPC가 돼요. 그룹 채팅에서도 돼요. 아래 "NPC 뽑기" 참고.

## 쓰는 법

1. 검사할 캐릭터의 카드를 눌러 **1:1 채팅을 연 뒤** 패널을 열어요. 지금 열린 채팅의 캐릭터가 검사 대상이에요(프로필 사진으로 확인). 그룹챗에서는 다섯 검사는 안 되고 NPC 뽑기만 돼요.
   - **카드 안의 인물** (0.6.0): 카드에 로어북 항목이 있으면 검사 대상 칸에 "누구를 검사하나" 목록이 떠요. 다인봇처럼 인물이 항목 하나씩으로 들어 있는 카드는 여기서 한 명을 골라요. 고르면 **그 항목 내용 + 카드 설명(세계관, 설정에서 끌 수 있음)**만 근거로 검사하고 다른 항목·로어북은 안 넣어요. 기록·종합 결과·공유용 요약이 인물마다 따로 생겨요(저장 키 `카드파일#entry:항목`). 결과는 그 항목 끝에 붙여 넣으면 돼요. "카드 자체"를 고르면 전과 같아요. 항목이 8개를 넘으면 이름 검색 칸이 같이 떠요.
2. (선택) **모델 연결**에서 연결 프로필을 고르면 RP와 다른 모델로 검사할 수 있어요. 비워 두면 지금 연결된 모델을 써요.
3. **로어북**: 기본은 상시(constant) 항목만. "켜진 항목 전부"로 바꾸면 더 많이 읽지만 호출마다 비용이 늘어요.
4. **한 번에 묶는 문항 수**: 기본 5 (1~10). 1이면 문항마다 호출(가장 정확, 가장 비쌈). 묶을수록 호출이 줄지만 앞 문항 답이 뒤 문항에 영향을 줄 수 있어요. 0.2.3에서 기본값이 1→5로 바뀌었고, 직접 바꾼 적이 없으면 저장된 1도 5로 올라가요.
5. 검사 옆 **시작**을 누르면 문항 수·로어북 상태와 비용 주의 문구를 보여 줘요. 확인하면 끝까지 자동으로 돌아요. 화면을 닫아도 계속돼요. **문항마다(또는 묶음마다) 모델을 한 번씩 부르므로, 캐싱이 안 되는 모델·연결에서는 비용이 클 수 있어요.**
6. 끝나면 **결과**에서 영역·세부 막대와 문항별 답·이유를 볼 수 있어요. 다른 칸을 누르면 "캐릭터는 n을 골랐어요. 바꾸시겠어요?" 팝업이 뜨고, 바꾸면 "제작자 수정"으로 표시되며 바로 다시 계산돼요. 캐릭터의 원래 답과 이유는 남아요.
7. 검사를 하나라도 끝내면 홈의 **종합 결과 보기**로 들어가요. 한눈에(문장 몇 줄) → 가치관(검사별 결과 + 갈리는 곳) → 성격(검사별 결과 + 갈리는 곳) → 내가 고친 것 → 공유용 요약 → 출처 순서예요. **공유용 요약 복사**로 카드나 로어북에 직접 붙여 넣어요. 형식은 아래 "공유 문구" 참고.

## 공유 문구 (카드에 붙여 넣는 것)

라벨만 나열하지 않고 **행동 문장이 본체, 라벨은 괄호 안 보조**예요. 모델이 이론을 몰라도 문장은 읽히고, 아는 모델은 괄호의 이론 이름·영어 라벨(예: `Moral Foundations (MFQ-2) · Care`)로 지식을 끌어와요.

```
[캐릭터 심리검사 요약]
[가치관 — 반응하는 일]
- 누가 다치거나 아파하거나 고통받는 장면: 그냥 못 지나친다 (MFQ-2 Care 중시·뚜렷)
- 노력·공로만큼 보상받지 못하거나 속임수가 통하는 장면: 바로잡으려 하고, 속인 쪽이 벌 받길 바란다 (MFQ-2 Proportionality 중시)
[가치관 — 넘어가는 일]
- 상스러운 말·방종·품위 없는 행동을 보는 장면: 거리낌 없이 넘긴다 (MFQ-2 Purity 낮음)
- 누구는 더 받고 누구는 덜 받는 장면: 몫이 달라도 신경 쓰지 않는다 (MFQ-2 Equality 낮음)
[가치관 — 갈리는 곳]
- 충성↓ 권위↓ 는 중간 — 상황 따라 반응하거나 넘김 (MFQ-2)
[성격 — 반응 모양]
- 남을 믿고 맞춰 주며 돕는다 (Big Five Agreeableness 높음 · 도덕성↑ 이타심↑)
- 사람과 혼자 사이를 오간다 (Big Five Extraversion 보통 · 쾌활함↑ 자극 추구↓)
- 남에게 잘 보이려 꾸미지 않고, 돈·지위·사치를 탐하지 않는다 (HEXACO Honesty-Humility 높음 · 꾸밈 없음↑ 탐욕 회피↑)
- 받은 것을 잊지 않고 고마움을 표현한다 (VIA Gratitude 높음)
- 농담을 잘 안 하고, 남을 웃기려 애쓰지 않는다 (VIA Humor 낮음)
[성격 — 갈리는 곳]
- 신경성·외향성·개방성·성실성↑ 은 전체 중간, 세부만 갈림 (Big Five)
- 용감함·희망 중간 (VIA)
※ 오락용 검사 결과. 라벨은 참고 자료이며 행동을 고정하는 규칙이 아니다. 갈리는 곳은 상황에 따라 달라질 수 있다.
```

- 칸 제목에 **가치관 / 성격** 축이 붙어요: 반응하는 일·넘어가는 일은 가치관 검사(MFQ-2·Schwartz)에서, 반응 모양은 성격 검사(Big Five·HEXACO·VIA)에서만 나와요. 갈리는 곳(중간·경계)도 각 축 안에 `[가치관 — 갈리는 곳]`, `[성격 — 갈리는 곳]`으로 들어가요.
- **[반응하는 일] 줄에는 장면 조건이 있어요.** 판단 엔진(예: CJ)이 카드 문단을 근거로 읽을 때, 조건 없는 라벨("MBTI: ISTJ")은 매 턴 상시 통과하거나 아예 안 쓰이지만, "〈장면〉: 반응"은 그 장면이 로그에 있을 때만 잡혀요. 가치관 줄은 카드의 설명(Description) 칸, 성격 줄은 성격(Personality) 칸에 넣는 걸 권해요.
- **강도(얼마나 세게)는 적지 않아요.** 세기는 장면의 사건 크기가 정하는 것이지 검사가 재는 값이 아니에요. 검사는 "무엇에 반응하나"와 "어떤 모양으로"만 줘요. 그걸 어느 단계에서 어떻게 쓸지는 RP 프롬프트가 정해요.
- 꼬리표는 **약칭 한 단어 + 영어 라벨 + 높/낮**(`MFQ-2 Care 중시·뚜렷`, `Big Five Agreeableness 높음`, `HEXACO`, `VIA`)만. 모델은 약칭만으로도 이론을 알아요.
- **환산 라벨(MBTI·A/T·에니어그램·대인 자세)은 0.5.0에서 뺐어요.** 빅파이브에서 계산으로 뽑던 값이라 직접 잰 게 아니고, 유형 글자가 캐릭터를 상투형으로 눌러요(사용자 결정). 도구 전체에서 라벨은 다섯 검사 것만 남아요. 0.4.x로 붙여 넣은 요약에 환산 줄이 있으면 직접 지우세요.
- **세부는 영역당 최대 2개**(뚜렷한 순)를 화살표로(`도덕성↑ 이타심↑`). 전부 보려면 검사별 결과 화면에서.
- **갈리는 곳**은 중간이거나 경계인 것 — 캐릭터가 상황에 따라 달리 행동할 수 있는 부분이에요. 모델이 글자 하나로 굳히지 않게 따로 적어요.

## 자료 우선순위 (프롬프트에 들어가는 규칙)

1. 카드 5칸(설명·성격·시나리오·대사 예시)과 로어북이 1순위.
2. 카드에 없는 부분은 모델의 원작 지식으로 채워도 되지만, 카드와 어긋나면 카드를 따름.
3. 원작 지식은 "왜 그런 판단 기준을 갖게 됐는지" 이해하는 데만. 원작 대표 행동·팬덤 고정관념을 그대로 답으로 삼지 않음.
4. 카드의 "MBTI: ISTP" 같은 라벨은 정답이 아님.

점수표(어느 답이 어느 축인지)는 모델에게 보내지 않고, 채점은 이 확장(`scoring.js`)이 해요. 모델 응답은 `{question_id, score, reason}` JSON만 받고, 키·ID·점수 범위·이유 길이를 검증해요. 틀리면 같은 묶음을 설정한 횟수(기본 5번)만큼 다시 묻고, 그래도 안 되면 멈추고 마지막 응답 원문을 보여 줘요. 임의로 채우지 않아요.

규칙·카드·로어북은 **시스템 메시지 앞쪽에 고정**하고 문항만 유저 메시지에 넣어요. 그래야 Gemini의 자동(암묵적) 캐시나 Claude의 시스템 프롬프트 캐시(ST `config.yaml`의 `claude.enableSystemPromptCache`)가 앞부분을 재사용할 수 있어요. 캐시가 실제로 적용되는지는 모델·연결에 따라 달라요.

### 빅파이브 30세부 (IPIP-NEO-120 원문) — 성격 본체

- 원형: **IPIP-NEO-120** (Johnson, 2014, *J. Research in Personality* 51). 문항은 IPIP(https://ipip.ori.org/) — **공개 도메인**. 120문항 목록·순서·세부·채점 방향은 MIT 저장소 `rubynor/bigfive-web`의 `en/questions.ts`에서 가져왔어요(Johnson의 IPIP-NEO-PI 소프트웨어 계통). 한국어 번역은 이 프로젝트의 것(같은 저장소의 한국어판을 참고했지만 오역이 많아 영어 기준으로 새로 옮김). 공식 NEO-PI-R이 아니에요.
- 5영역(신경성·외향성·개방성·우호성·성실성) × 6세부 × 4문항. 세부마다 -8~+8, 영역마다 -48~+48로 더해 비율 ≥30% 높음, ≤-30% 낮음, 사이 보통. 결과 화면에 영역·세부 막대 35개가 다 나와요.
- 0.3.0~0.4.2에는 여기서 MBTI·A/T·에니어그램(Hook 외 2021)·대인 자세(IPC) 근사 환산을 붙였지만 0.5.0에서 뺐어요(`derive.js`·`tests/mbti-tables.js` 삭제).

### 꾸밈 없음 · 탐욕 회피 (IPIP-HEXACO 발췌)

- 원형: **IPIP-HEXACO** Honesty-Humility 척도 (https://ipip.ori.org/newHEXACO_PI_key.htm) — **공개 도메인**. 공식 HEXACO-PI-R이 아니에요.
- 정직-겸손 4세부 중 **공정(Fairness)·겸손(Modesty)은 뺐어요** — IPIP-NEO의 우호성 세부 도덕성(A2)·겸손(A5)과 문항까지 거의 같아서 빅파이브 검사와 중복이에요. 빅파이브에 대응물이 없는 **꾸밈 없음(Sincerity)·탐욕 회피(Greed Avoidance)**만 남기고 세부당 10문항 중 8문항을 골라 번역했어요. 채점은 빅파이브와 같은 방식.

### Schwartz 10가치 (PVQ40 한국어판 원문)

- 원형: **Portrait Values Questionnaire 40 (PVQ40 / PQ IV)**, Shalom H. Schwartz. 출처: Schwartz (2012), *A Repository of Schwartz Value Scales with Instructions and an Introduction*, Online Readings in Psychology and Culture 2(2) — https://scholarworks.gvsu.edu/orpc/vol2/iss2/9/ . 파일 "PQ IV Korean"(한국어 번역 Shang Hui Shin, 2008)과 "Coding Key PVQ40"(2021).
- **라이선스: CC BY-NC-ND 3.0** — 출처 표기, **비상업**, **수정 금지**. 그래서 40문항을 한 글자도 바꾸지 않았어요(공백 정리만). 남성판·여성판 둘 다 원문 그대로 들어 있고, 한국어판 여성판은 "남성→여성"만 바뀌고 "그"는 그대로이며 17번에 원문 오타가 있는데 그것도 그대로예요. 채점표 머리글의 원저자 안내도 옮겨 둬요: *"The PVQ40 is available at no cost for academic research purposes. For commercial use, a license is required. Contact shalom.schwartz@huji.ac.il."* 이 도구는 비상업 오락용이에요. **상업적으로 배포하려면 이 검사는 빼거나 원저자 라이선스를 받아야 해요.**
- 형식: "어떤 남성/여성에 대한 묘사"를 읽고 그 사람이 나와 얼마나 같은지 **1~6**(나와 전혀 같지 않다 … 나와 매우 같다). 설정의 **Schwartz 초상문 성별**로 남성판/여성판을 고른 뒤 시작하면 그 기록에 고정돼요. 프롬프트에 "묘사 속 남성/여성·그는 묘사 대상을 가리키는 말이니 캐릭터 성별과 달라도 내용만 보고 답하라"는 안내를 붙여요.
- 채점은 채점표대로: 10가치 = 소속 문항 평균, **개인 전체 평균(MRAT)을 빼서 중심화**(원저자가 권하는 방식 — 가치는 절대량이 아니라 서로 간의 우선순위로 작동하니까). 4방향 = 소속 가치의 평균. 중시/보통/넘김 구간(중심화 점수 ±0.6)은 이 도구의 자체 기준이에요.
- 10가치 한국어 이름: 자기지향·자극·쾌락·성취·권력·안전·순응·전통·박애·보편주의. 공유 문구에는 가치마다 "〈장면〉: 반응" 줄과 "가치 방향(센 순)" 한 줄이 들어가요.

### 도덕 기반 6개 (MFQ-2 원문)

- 원형: **Moral Foundations Questionnaire-2 (MFQ-2)** — Atari, Haidt, Graham, Koleva, Stevens & Dehghani (2023), *Morality Beyond the WEIRD*, JPSP. 원저자 OSF 프로젝트 https://osf.io/srtxn/ — **CC BY 4.0** (https://creativecommons.org/licenses/by/4.0/). 영어판 파일 https://osf.io/6bfe9, 일본어판 https://osf.io/t2hbd.
- 영어판 **36문항 전체를 순서·내용 그대로** 가져와 한국어로 번역했어요(일본어판 대조). 문항을 고르거나 고치지 않았어요. 번역은 이 프로젝트의 것이며 원저자의 공식 번역이 아니고, 원저자의 승인·후원을 뜻하지 않아요.
- 6기반: 배려(Care)·평등(Equality)·비례(Proportionality)·충성(Loyalty)·권위(Authority)·순수(Purity), 기반당 6문항, 전부 정채점. 척도는 "이 문장이 당신을 얼마나 잘 묘사하는가" 1~5.
- 기반마다 -12~+12로 더해 비율 ≥30%면 **중시**, ≤-30%면 **넘김**, 사이는 **보통**. 이 구간은 이 도구의 자체 기준이지 원저자의 것이 아니에요. 화면에는 원 척도 평균(1~5)도 같이 보여요.
- 문항이 현대 사회 기준("나라에 충성", "수입이 같다면")이라, 프롬프트에 "나라·사회·수입은 캐릭터 세계의 대응물(소속 집단·공동체·재물과 몫)로 읽어라"는 한 줄을 붙여요. 문항 자체는 바꾸지 않아요.

### VIA 강점 5개 (IPIP-VIA 발췌)

- 원형: **IPIP-VIA** 24강점 척도 (https://ipip.ori.org/newVIAKey.htm) — **공개 도메인**. 공식 VIA-IS가 아니에요.
- 24강점 중 빅파이브 30세부로 잡히지 않거나 약하게만 잡히는 다섯 개만 남겼어요: **유머·감사·용감함·희망·통찰**. 나머지 19강점(친절≈이타심, 끈기≈자기 규율, 호기심≈지적 호기심 …)은 빅파이브로 대신해요. 강점마다 8~10문항 중 6문항을 골라 번역했어요. 강점 하나가 영역 하나라 합산하지 않고, 강점마다 높음/보통/낮음.

### 0.2.x에 있던 검사 (목록에서 뺌)

- **MBTI 4축(OJTS 단축판 20)**: 네 축 전부 빅파이브(외향성·개방성·우호성·성실성)와 겹치고, 20문항이라 경계 축이 재검사마다 뒤집혔어요(실제 신파치: ESFJ→ESFP). 빅파이브에서 환산한 네 글자로 대체. 0.3.2에서 OJTS 문항(CC BY-NC-SA)은 파일째 삭제했고, 환산용 표(기능 순서·글자 설명)만 `tests/mbti-tables.js`에 남아 있어요 — 이 표는 특정 검사의 저작물이 아닌 일반 지식이에요. 그래서 배포물에 남는 외부 라이선스는 **공개 도메인(IPIP)과 CC BY 4.0(MFQ-2)뿐**이에요.
- **정서 안정성(IPIP 5)**: 빅파이브 신경성(24문항)과 같은 것.
- 옛 기록(MBTI·정서 안정성·옛 VIA·옛 정직-겸손)은 설정 파일에 남지만 화면에는 안 보여요.

## NPC 뽑기 (0.5.0, 간소화판)

다인봇에서 모델이 즉석으로 굴리는 NPC는 다 비슷해지기 쉬워요. 그래서 **검사 문항 없이** 한 번 추측해서 라벨 세 줄로 박아 넣는 기능이에요. 본 캐릭터는 라벨이 캐릭터를 누르니까 행동 문장으로 적지만, NPC는 반대로 "싸게·서로 다르게·모델이 알아서 펼치게"가 목적이라 라벨이 맞아요. 라벨 어휘는 본 검사 다섯 개와 **똑같아요** — 프롬프트(CJ)가 본 캐릭터 요약과 NPC 줄을 같은 방식으로 읽게 하려고요.

홈의 **NPC 뽑기** 카드에서 들어가요. 1:1·그룹 채팅 어디서나 열려요. **뽑은 NPC와 입력 칸 초안은 그 채팅방(채팅 파일의 메타데이터)에 저장**돼서 다른 채팅에서는 안 보이고, 채팅을 지우면 같이 지워져요. 그래서 채팅을 열지 않은 상태에서는 쓸 수 없어요(저장할 곳이 없어서).

입력:
- **이름** — 로그에 나오는 그 이름 그대로. 모델은 이 이름의 말과 행동만 근거로 삼아요.
- **이미 만든 설정** (선택) — 로어북·메모에 적어 둔 걸 붙여 넣어요. **정답**으로 들어가서 로그보다 우선해요. 봇 테스터의 "위키" 칸과 같은 역할.
- **전형** (선택) — 악역 · 교활한 조력자/배신자 · 선한 조연 · 멘토/현자 · 코믹 릴리프 · 냉정한 전문가 · 순박한 마을 사람 · 권위자 · 상인 · 호위/전사, 또는 직접 적기. 자료에 안 드러난 칸만 그 역할의 전형 쪽으로 기울여요. **약간** = 표에서 센 것 3칸, **뚜렷** = 표 전부. 고른 전형은 확장의 표(`npc.js`의 `ARCHETYPES`)대로 채우고, 직접 적은 전형은 모델이 알아서 기울여요(3칸까지).
- **다른 인물과 겹치지 않게** (체크) — 전에 뽑은 세 줄을 붙여 넣는 칸이 생겨요. **＋**로 칸을 늘려요. 확장이 그 세 줄의 ↑↓를 되읽어서, 자료에 안 드러난 칸을 그들과 다른 쪽으로 채워요(최대 4칸). 모델에게는 보내지 않아요. 이 도구가 만든 세 줄 틀이어야 읽혀요(자유 서술은 못 읽음).
- **로그** — 지금 열린 채팅의 최근 N자(기본 30,000). 숨긴 메시지는 안 읽어요.

뽑기 = 모델 호출 1번. 모델은 28개 항목마다 `high / mid / low / unknown`만 고르고(자료에 드러나지 않으면 반드시 unknown), 글을 짓는 건 첫 줄(자리·말투)뿐이에요. 틀린 응답은 걸러서 재시도해요(설정의 재시도 횟수).

채우는 순서: **자료에 드러난 것 → 전형 → 겹치지 않게 → 남으면 중간(생략)**.

결과:
```
[모르간] 상인 길드장, 40대. 겉으로는 일행의 후원자, 뒤로는 경쟁 상단을 무너뜨렸다. 말투: 정중한 존댓말, 끝을 흐리며 웃는다.
가치관: 비례↑ 권위↓ (MFQ-2) · 자극↑ 성취↑ 권력↑ 안전↓ 전통↓ · 자기 고양 > 보존 (Schwartz)
성격: 성실성↑ 우호성↓ (Big Five) · 꾸밈 없음↓ 탐욕 회피↓ (HEXACO) · 통찰↑ 감사↓ (VIA)
```
- 높/낮만 적고 중간은 생략해서 60~100토큰. Schwartz 4방향은 양쪽이 다 기울 때만 `A > B`로.
- 화면에서는 각 라벨이 어디서 왔는지 보여요 — 설정·로그(그냥 글자), 전형(노란 밑줄), 겹치지 않게(초록 밑줄). 복사하면 밑줄 없이 글만 가요.
- **겹침**: 붙여 넣은 인물마다 같은 방향 칸이 몇 개인지 세요. **다르게 다시**를 누르면 겹친 칸을 참고로 붙여 한 번 더 뽑고, 겹치지 않게 칸도 다른 후보를 잡아요.
- **첫 줄 고치기**로 자리·말투만 손볼 수 있어요. 라벨은 안 바뀌어요.
- 뽑은 NPC는 **이 채팅방의** 목록에 남아요(최신 200개). 로어북에 자동으로 넣지 않아요 — 복사해서 항목을 만들고 키워드를 이름으로 두면 돼요. 다른 채팅에서 같은 NPC를 쓰려면 로어북 쪽 글을 쓰면 돼요(그게 고정 NPC의 본체).

1. 캐릭터 선택 드롭다운 삭제. **지금 열린 1:1 채팅의 캐릭터**로 고정하고 프로필 사진을 보여 줘요. 그룹챗·채팅 없음이면 안내만.
2. 응답 검증 실패 시 **자동 재시도** (기본 5번, 설정 가능). 다 써서 멈출 때만 마지막 응답 원문을 저장하고 오류 칸에서 펼쳐 볼 수 있어요.
3. 교체 팝업 제목 "아쉽네요" → "답 바꾸기".
4. 시작 팝업에서 호출 횟수·토큰 어림값 삭제, 비용 주의 문구로 대체. 설정의 "끝났을 때 예상 사용 토큰 보여 주기"(기본 꺼짐)를 켠 경우에만 완료 후 어림값 표시.
5. 카드·로어북을 시스템 메시지로 이동(프롬프트 캐시에 유리하게).
6. 새 검사: VIA 6덕목(30), 정서 안정성(5). 1~5 동의 척도.

## 휴대폰에서 확인할 순서 (0.5.0)

1. 홈에 **검사 대상 / 가치관 / 성격 / 종합 결과 / NPC 뽑기** 칸이 보이는지. 옛 기록(0.4.x 완료)은 그대로 "완료"로 남아 있는 게 정상.
2. 빅파이브 **결과**를 열었을 때 위쪽의 "환산(직접 측정 아님)…" 상자가 **없는지**, 영역·세부 막대는 그대로인지. **종합 결과 → 공유용 요약**에도 환산 줄이 없는지(이미 카드에 붙여 둔 요약에는 남아 있으니 거기서 직접 지우기).
3. **그룹 채팅을 연 채로** 패널을 열어 "NPC 뽑기" 카드가 뜨는지 → NPC 뽑기 → 이름·설정 적고 **뽑기** → 모델 호출 1번 뒤 세 줄이 나오는지. 설정의 연결 프로필·재시도 횟수·응답 토큰 상한이 그대로 적용돼요.
4. 전형을 "악역(약간)"으로 두고 뽑아 노란 밑줄이 최대 3칸인지. "다른 인물과 겹치지 않게"를 켜고 전에 뽑은 세 줄을 붙여 넣어 "읽음: 이름 · 라벨 n개"가 뜨는지, 뽑은 뒤 초록 밑줄과 "겹침: …와 n칸"이 보이는지.
5. **복사** → 로어북 항목에 붙여 넣기(밑줄 없이 세 줄만 가는지). **다르게 다시** → 목록에 하나 더 쌓이는지. **첫 줄 고치기** 팝업이 두 번(자리 → 말투) 뜨는지.
6. 다른 채팅(1:1)으로 가면 그룹챗에서 뽑은 NPC가 목록에 **안 보이는지**, 돌아오면 다시 보이는지. 채팅을 닫은 상태에서는 NPC 뽑기 카드에 "채팅을 열면 쓸 수 있어요" 안내만 나오는지.
7. (0.6.0) 다인봇 카드(예: 닌자 학원 RPG)로 1:1 채팅을 열면 검사 대상에 "누구를 검사하나" 목록과 이름 검색 칸이 뜨는지 → 한 명 고르면 제목이 "카드 › 인물"로 바뀌고 검사 기록이 비어 있는지 → 시작 팝업에 "카드 안의 인물 · 항목 … + 카드 설명"이 나오는지 → 끝난 뒤 공유용 요약을 그 항목에 붙일 수 있는지. 다른 인물로 바꾸면 기록이 따로인지.
